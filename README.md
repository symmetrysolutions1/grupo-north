# Grupo North Benchmark

Aplicativo web local para registrar visitas comerciales, cargar evidencias y consultar el panorama competitivo de marcas, precios, calidad y posicionamiento.

## Ejecutar localmente

Como es una aplicación estática, puede abrirse directamente con `index.html`. Para servirla en localhost con Node.js:

```bash
npx serve .
```

Luego abrir `http://localhost:3000`.

## Alcance actual

- Portada de Grupo North.
- Registro guiado de visitas comerciales.
- Repositorio visual de evidencias.
- Centro de control con señal de mercado.
- Comparador de marcas con selectores y exportación CSV.
- Persistencia local mediante `localStorage` para la demostración.

Este repositorio contiene un prototipo funcional de interfaz. La autenticación, base de datos compartida, almacenamiento de archivos y publicación productiva quedan para la siguiente etapa.
